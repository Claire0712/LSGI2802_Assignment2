## Reproduce this repository

```sh
git clone https://github.com/Claire0712/LSGI2802_Assignment.git
cd LSGI2802_Assignment
```

This package preserves the analytical snapshot used to study walking access to public primary care in Hong Kong. It contains the source scripts, unit tests, pinned analytical dependencies, original data downloads, frozen origin–destination (OD) matrices and the reported numerical outputs. The repository is self-contained for offline verification after cloning.

## Set up Python

Use Python 3.12 from the cloned `LSGI2802_Assignment` directory:

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows, activate with `.venv\Scripts\Activate.ps1` in PowerShell. The recorded analytical environment used Python 3.12.14; exact package versions are in `requirements.txt` and `ENVIRONMENT.json`. The package excludes host-specific runtime dependencies. Plotting copies register Arial when available and otherwise use a bundled DejaVu Sans fallback; font appearance may differ between systems.

## Quick verification: no network rerouting

```sh
python reproduce.py verify
```

This command checks the original-data checksums, installed dependency versions, metrics recalculated from all five frozen OD matrices, threshold/decay sensitivities, correlation and tie-retaining low-set comparisons, disagreement cases, walking-speed effects, uncovered-route scenarios and alternative-origin classifications. It then runs the eight unit tests. It does not calculate new routes or access the Internet.

The packaging check passed **56 numerical/environment checks, 12 raw-file checksum checks and all 8 unit tests**. Records are in `validation/offline_verification.json` and `validation/unit_tests.txt`. Verification was performed using the existing Python 3.12.14 environment. A fresh installation in a separate environment and a complete network rerouting were not executed during packaging.

## Full rebuild from the frozen raw snapshot

```sh
python reproduce.py full
```

This is a separate, substantially heavier operation. It extracts the included official network ZIP, rebuilds the network, selects origins, calculates routes for all scenarios, regenerates numerical summaries and figures, and runs the checks. No execution-time estimate is provided. Run it in a working copy if the archived results must remain byte-identical.

The entry point uses this order:

1. `download_full_network.py` extracts the included ZIP; it does not download while that ZIP exists.
2. `prepare_geography.py` prepares TPUs, census geography and the 74 clinic sites.
3. `build_network.py` creates the directed, time-filtered 3D network and an exact-XYZ backup.
4. `repair_topology.py` applies the bounded sub-decimetre joins to that backup.
5. `select_origins.py` creates census-guided proxies and clinic connectors.
6. `analyse.py` computes the five scenarios, indicators and sensitivity outputs.
7. `scenario_comparisons.py` regenerates the baseline–scenario gravity rank/low-set comparisons.
8. `plot_results.py` generates the comparison plot and GIS results; `plot_accessibility_labeled.py` generates the blue labelled map used in the manuscript.
9. `route_audit.py`, `audit_disconnections.py` and `plot_route_pages.py` regenerate route checks and the two audit pages.
10. `offline_verify.py` and the unit tests check the rebuilt outputs.

The calculation scripts check input fingerprints before reusing OD caches. The package contains the frozen OD matrices for immediate verification, but excludes the large derived network arrays; full rebuilding regenerates them.

For only the two main plots from frozen numerical outputs, without routing:

```sh
python reproduce.py figures
```

This prepares geography from the included raw JSON and regenerates the main maps/scatterplots. Route-audit images require the derived network and are generated by `full`.

## Interpretation and outputs

The reference is an ordinary non-holiday Monday at 15:00, with 74 equally weighted clinic sites and 284 resolved proxies across 292 TPUs. Baseline walking is 4.8 km/h; the slow scenario is 3.0 km/h. Lifts retain 60 m/min traversal costs without waiting. The 15-minute cumulative threshold and 15-minute gravity half-life are separate parameters. Uncovered-edge scenarios use illustrative generalised-cost penalties, not observed thermal effects.

`results/` contains the archived OD matrices, per-origin measures, comparisons, sensitivity tables, summary statistics and audit records. The reported correlations use 271 reachable origins; low-set comparisons use 284 resolved origins and retain boundary ties. Counts represent modelled proxy locations, not percentages of residents. Geometric route checks do not establish actual entrance access or real journey times.

After regeneration, the manuscript's main figure files are:

- `figures/accessibility_maps_paper_labels_v2.png` — use this labelled blue map, not the older map generated as `accessibility_maps.png` by `plot_results.py`.
- `figures/comparison.png`.
- `figures/route_audit_portrait_page_1.png` and `figures/route_audit_portrait_page_2.png`: supplied portrait figures; full rebuilding regenerates four rows by three columns for A4 portrait appendices. The earlier landscape PNGs are retained separately in the original project.

The manuscript's downloaded root `accessibility_maps.png` was byte-identical to the labelled-map file at packaging. The repository manifest was refreshed after repository preparation. Old DOCX/report/Overleaf writers are excluded so rerunning the analytical package cannot regenerate or replace the superseded report text.
