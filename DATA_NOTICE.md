# Data attribution and scope

This repository preserves the public CSDI snapshot used for the paper. Provider catalogue links, retrieval dates and SHA-256 checksums are documented in README.md and the source manifests. Data remain subject to their providers' terms; this repository does not relicense third-party data. No participant-level medical records are included.

The source archive and raw JSON files are deliberately retained for reproducibility. Derived network arrays and extracted FGDB directories are regenerated by `python reproduce.py full` and are ignored by Git.
